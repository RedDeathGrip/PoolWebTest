Pool Web Test

Purpose: prove that the Miniclip web version of 8 Ball Pool loads and is playable inside a sideloaded iPhone app.

Build:
1. Create a new GitHub repository.
2. Upload all files/folders from this ZIP, preserving .github/workflows/build.yml.
3. Open Actions -> Build PoolWebTest IPA -> Run workflow.
4. Download the PoolWebTest-IPA artifact.
5. Extract it and install PoolWebTest.ipa using SideStore.
